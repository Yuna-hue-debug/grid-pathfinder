# grid-pathfinder
An AI agent for grid-based pathfinding and decision making.

## Project Goal

This project aims to build an intelligent agent capable of navigating a grid world, collecting resources, and making strategic decisions under dynamic environments.

The project is inspired by the GoldRush programming competition and is developed as part of the Polymer Tech Expo 2026.

---
